    这个开源项目整理了 Windows PowerShell、Linux、国产 Linux、Docker/Kubernetes、常见故障排查和自动化巡检脚本，适合日常查命令、值班排障、团队培训和内部知识库沉淀。

    # 从命令速查到自动化巡检: 我整理了一份 PowerShell 与 Linux 中文运维手册

## v2.16.0 重点更新

### 1. 主手册最终收口

根目录主手册从几千行长正文收口为总导航和历史说明，真正的命令正文进入专题页、路线页和故障案例库，后续维护成本更低。

### 2. 巡检脚本继续工具化

巡检脚本现在支持:

- `system`
- `disk`
- `network`
- `service`
- `process`
- `package`
- `security`
- `container`
- `log`

Linux 示例:

```bash
bash scripts/linux-health-check.sh --module security --format json
bash scripts/linux-health-check.sh --module log --format markdown --output reports/linux-log.md
```

Windows 示例:

```powershell
.\scripts\windows-health-check.ps1 -Module package -Format json
.\scripts\windows-health-check.ps1 -Module container -Format markdown -OutputFile reports\windows-container.md
```

### 3. 真实故障案例扩展

新增了更贴近生产的案例:

- 网关超时
- 负载均衡健康检查失败
- 消息队列连接失败
- 数据库连接池耗尽
- Prometheus 告警规则误报

每个案例都按“现象 -> 快速判断 -> 排查命令 -> 常见原因 -> 处理建议 -> 高危提醒 -> 相关专题”的结构编写。

### 4. PDF 自动导出

新增 `PDF Export` GitHub Actions 工作流，可以手动导出重点页面 PDF，适合 Release 附件、内部知识库归档和离线阅读。

    发布前检查¶

    • GitHub Actions 主要工作流为绿色。
    • GitHub Pages 首页可打开。
    • Release 链接可打开。
    • 文章中的 GitHub、文档站、Release 链接有效。
    • 代码块语言标识正确，例如 bash、powershell、json。
    • 示例中没有真实 IP、密码、Token、内网域名。
    • 文末包含 Star、Issue、PR 或贡献入口。

    发布后动作¶

    • 在 README 或 Release 中确认文章链接是否需要回链。
    • 观察 GitHub Stars、Issues、Forks 和 Pages 访问反馈。
    • 将读者反馈整理成新的 Good First Issues。
