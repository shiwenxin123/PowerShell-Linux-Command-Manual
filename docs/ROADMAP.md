# Roadmap

这个路线图用于说明项目后续扩展方向，方便贡献者选择任务。

## 近期

- 完成主手册最终收口: 将根目录主手册压缩为总目录、历史说明和专题入口。
- 扩展巡检脚本模块: package、security、container、log。
- 继续扩展真实故障案例库，增加网关超时、云负载均衡健康检查失败、消息队列连接失败、数据库连接池耗尽和 Prometheus 告警规则误报。
- 优化文档站路线入口: 新手路线、运维值班路线、国产 Linux 路线、Kubernetes 排障路线。

## 中期

- 增加离线 PDF 发布流程。
- 增加更多国产 Linux 真实版本案例和离线源目录示例。
- 增加 Prometheus/Grafana/Loki 真实告警案例。
- 将高危命令风险等级继续回填到具体专题页。

## 长期

- 建立版本化发布节奏。
- 持续维护 good first issue 任务池。
- 形成中文运维命令知识库。
